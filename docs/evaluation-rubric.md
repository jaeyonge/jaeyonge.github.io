# Evaluation rubric

| Area              | Evidence required                                                                                                            |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Facts             | Traceable basis for amounts, dates, role and comparison baseline; no invented causality or future target treated as achieved |
| Core strength     | Concrete connection between business decision, detailed verification, repeatable standards and automation                    |
| Research          | Data/question, personal contribution and verification clear; paper link retained                                             |
| Bilingual quality | Meaning, status, scope, units and figures match; natural English/Korean; counterpart reviewed                                |
| Structure         | Fixed five-section order, three selected bullets/company and three/research; Gyeongnam school retained                       |
| Assets            | Public files tracked and load without sources; no rectangular school-background artifact; SNU readable in dark mode          |
| UI                | Responsive reading width, focus/labels, no overflow, visible content without JS, reduced motion                              |
| PDF               | Selectable text, real paper/contact links, embedded fonts, no blank/cut pages, same content hash/profile; readable type      |
| Reproducibility   | Frozen dependencies, recorded design ref, clean build without private sources, no local absolute paths                       |
| Iteration         | Actual defect → targeted fix → recheck record; no claims of independent human review                                         |

Required factual, asset or build failures block release. Current PDF target is at most three A4 pages per language at 9.5pt body; if overflow occurs, review selection/spacing/content rather than shrink text invisibly. Automated accessibility checks and self-review do not establish complete accessibility or predict hiring outcomes.
